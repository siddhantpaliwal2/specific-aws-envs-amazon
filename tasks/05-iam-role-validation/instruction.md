Before saving a customer's scraper role, prove it can be assumed with the supplied external id and that the returned credentials can read the instance inventory used by collection. Failure of either check is a bad request and nothing else in that save may be written. A blank role means disconnect and must clear the external id; a settings block that names no role is invalid rather than a disconnect. This task includes a local AWS-compatible emulator at the preconfigured AWS_ENDPOINT_URL. Its credentials and region are already in the shell, repository AWS clients use it, no real AWS account is involved, and you may inspect its resources while working.
